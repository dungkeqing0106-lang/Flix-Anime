Cài đặt API

Mặc định dùng API công khai của Consumet. Nếu nó chậm hoặc lỗi, dán địa chỉ bản Consumet bạn tự host (phải là https khi dùng trên điện thoại). localhost chỉ dùng được khi mở file trên chính máy chạy server.
Dùng khi nguồn phát yêu cầu Referer mà trình duyệt không gửi được. {url} và {headers} sẽ được thay thế tự động.
